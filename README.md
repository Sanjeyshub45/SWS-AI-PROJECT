## About the App

SWS AI Docs is designed for students and staff who need a simple way to manage PDF files from their mobile devices. Users can upload documents, track upload progress, organize files, and receive notifications when uploads are completed or fail.

The application focuses on simplicity, responsiveness, and a clean user experience.

---

## Features

### PDF Upload
- Upload one or multiple PDF files
- Real-time upload progress tracking
- Background uploading support for larger batches
- Upload status updates for every file
- Automatic success and failure handling

### Document Library
- View all uploaded documents in one place
- Displays file name, size, and upload date
- Open PDFs directly in the browser
- Delete documents permanently from storage

### Notifications
- Stores upload notifications in the cloud
- Notifications remain available after restarting the app
- Unread notification badge support
- Mark notifications as read
- Swipe to dismiss notifications
- Clear all or mark all as read
- Local push notifications after upload completion

## Running the Project Locally

### Prerequisites
- Flutter SDK
- Android Studio
- Firebase Project
- Android device or emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/Sanjeyshub45/SWS-AI-PROJECT.git

# Navigate to the project
cd SWS-AI-PROJECT/sws_ai_docs

# Install dependencies
flutter pub get

# Run the application
flutter run
